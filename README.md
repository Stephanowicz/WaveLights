# WaveLights
threeJS Fluid Waves

<img width="2146" height="542" alt="image" src="https://github.com/user-attachments/assets/122b2348-ac11-4efe-a04a-d2d0089e5bcf" />

This was inspired by [Fluid-Wave-by-domox](https://images.squarespace-cdn.com/content/v1/54752eb3e4b0d8c535b1ff34/1418076501761-9PBRTFGNW2XZEWTNU67B/Fluid-Wave-by-domox%281%29.jpg?format=2500w) 
And the initial idea for the code was inspired by [sabosugi](https://codepen.io/sabosugi/pens/showcase) 
 
I tried different things - the first result was [this](https://codepen.io/stephanowicz/pen/myOjaEp)  
Finally, after trying different procedural noises, I stuck with [SimplexNoise](https://www.shadertoy.com/view/XsX3zB) by Nikita Miropolskiy  
Unfortunately, it is very GPU-intensive in fullscreen 

I was thinking of using a noise texture instead, but I haven't gotten very far with that yet

During devlopment, I wanted to understand all params that influence the waves - so the 'scene settings' have lot of options for manipulating and playing
  
Enjoy and have fun!
